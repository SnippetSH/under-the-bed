# M5 참고 수치 (토양 쪽 재조사): 태양열·약제 소독, 소독 뒤 질소·망간, 토양병, 유익균, 멀칭

[m5-microbes-disease.md](m5-microbes-disease.md)(1차 조사)의 토양 쪽 값을 **원문을 직접 읽고** 다시 확인한 자료예요.
확인 날짜는 모두 2026-11-19예요. 수치는 요약만 적었고 원문 문장은 옮기지 않았어요.

**신뢰도 표기 (이 문서 기준, 1차 조사보다 엄격해요)**

- **높음**: 1차 출처(논문·공공기관 지침·제품 라벨) 원문의 표·그림·본문에서 직접 읽음. 작물·조건도 딸기 하우스와 같거나 매우 가까움
- **중간**: 1차 출처 원문을 읽었지만 작물·조건(실험실, 다른 작물, 다른 나라)이 다름
- **낮음**: 초록·검색 요약·2차 인용만 확인
- **출처 미확인**: 이번에도 근거를 못 찾음. 디렉터 확인 전에는 "게임용 임의값"

그림에서 읽은 값은 "그림 판독"이라고 적었어요(±10% 정도 오차).
