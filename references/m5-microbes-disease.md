# M5 참고 수치: 미생물·소독·병해충·하우스 습도

M5 명세와 보정(calibration)의 목표 범위를 잡기 위한 자료예요. 확인 날짜는 모두 2026-11-19예요.
수치는 요약만 적었고, 원문은 복사하지 않았어요.

**신뢰도 표기**: 높음 = 공개 출처에서 직접 확인, 중간 = 출처는 있지만 작물·조건이 다르거나 간접 확인, 낮음 = 일반 문헌 지식 수준.
**"출처 미확인"** = 이번 조사에서 근거를 못 찾았고 일반 지식으로 적은 범위예요. 디렉터가 확인하기 전에는 "게임용 임의값"으로 다뤄요.
이번 조사는 검색 도구 제약(웹 검색 요약만 가능, 원문 PDF 미열람) 때문에 원문 대조를 못 했어요. 표의 "높음"도 검색 요약 기준이라, 중요한 값은 원문 재확인이 필요해요.
