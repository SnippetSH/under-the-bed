# M5b 근거 조사: 하우스 수증기·공기 흐름·지상부 병해충 (3차 조사)

M5b 초안([house-humidity](../docs/spec/house-humidity.md), [foliar-disease](../docs/spec/foliar-disease.md), [m5-overview](../docs/spec/m5-overview.md) 5장 B1~B10·9장 S26~S32)의 수치와 곡선마다 근거를 붙이려고 조사했어요.
[m5-foliar-humidity.md](m5-foliar-humidity.md)(2차)와 [m5-microbes-disease.md](m5-microbes-disease.md)(1차)를 **대체하지 않고 덧붙여요**. 같은 항목의 값이 다르면 이 파일이 우선이에요.

- 확인일: 모두 2026-11-19. 수치만 요약했고 원문 문장은 옮기지 않았어요.
- 범위: 조사만 했어요. 명세·데이터·코드는 바꾸지 않았어요(제안은 5장 비교 표와 7장 질문으로만).
- 출처 번호: 이번에 새로 확인한 출처는 **[S번호]**예요. 주제별로 번호대를 나눴어요: S1xx 수증기 수지, S2xx 공기 흐름·잎 마름, S3xx 병해, S4xx 응애. **"기존 [H1]" 같은 표기**는 [m5-foliar-humidity.md](m5-foliar-humidity.md) 출처 목록의 번호예요. 기존 [H1]~[H3], [H7]은 다시 열어 확인해서 S115~S117, S108로도 실었어요.
- 같은 자료가 두 번호대에 나온 경우 하나로 합쳤어요: 오이타현 판단 도구는 [S110], van Westreenen 2020은 [S111].
- "자체 계산" = 출처의 공식으로 이번에 직접 계산한 값이에요(실측 아님).

**신뢰도 표기**
- 높음 = 1차 출처(논문 본문·표, 기관 공식 자료)를 직접 열어 확인했고 작물·조건이 맞음
- 중간 = 1차 출처를 직접 열었지만 작물·조건이 다르거나(토마토·오이·다른 병원균 종), 초록만 확인함
- 낮음 = 검색 요약·2차 인용·비학술 자료만 확인함
- 출처 미확인 = 근거를 못 찾았어요. 지어내지 않고 "게임용 임의값" 후보로 남겨요.
