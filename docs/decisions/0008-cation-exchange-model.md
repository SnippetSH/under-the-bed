# ADR-0008: 양이온 교환은 "빈자리 경쟁 + 완화"로 근사

- 상태: 승인 (2026-11-18)
- 날짜: 2026-11-18

## 맥락

M3에서 CEC 자리와 토양 용액 사이의 양이온 분포를 계산해야 해요(계획서 4장 7번: 평형 쪽으로 서서히 이동, 이온별 선택 계수). 필요한 성질은 아래예요.

1. CEC가 낮으면 같은 투입에도 용액 쪽 변동이 커요 (S6).
2. 한 이온을 많이 넣으면 다른 이온이 용액으로 밀려나요 (S5).
3. 자리보다 양이온이 많으면 남는 것은 반드시 용액에 있어요(교환성 합 ≤ CEC).
4. 원소별 보존, 음수 없음, 결정론, 극한 입력에서 NaN 없음.
5. M2 결과(고정 용액 비율)에서 크게 벗어나지 않고 출발해요.

## 결정

1. **경쟁 랭뮤어(빈자리) 근사**: 이온마다 세기 `w_i` 하나를 두고, 빈자리 비율 φ를 `cec × (1 − φ) = Σ T_i·w_i·φ / (1 + w_i·φ)`의 해로 구해요. 이분법을 **고정 횟수** 반복해요.
2. **완화**: 용액 양은 평형값 쪽으로 시간당 `exchange_rate_per_hour` 비율만큼 움직여요. 투입은 먼저 용액으로 들어가요.
3. **φ와 pH는 연결하지 않아요.** pH는 M2 산·염기 수지만 맡아요.
4. 망간은 같은 틀에서 세기를 이동성(pH × 산소)으로 나눠 처리해요(ADR-0007).

## 근거

- 성질 1~3을 식 하나로 만족해요. 특히 3번(자리 포화 시 남는 양이 용액으로)은 고정 분배계수(Kd)나 단순 비례식으로는 안 돼요. 고정 비율식은 CEC를 넘게 붙잡을 수 있어요.
- 해가 하나뿐이고(양쪽이 φ에 대해 단조), 이분법 고정 반복이라 결정론과 수치 안전이 쉬워요. 셀 80개 × 8,760틱 × 60회도 1년 실행에 부담이 없어요.
- 세기 w를 "기준 토양에서 M2 용액 비율이 나오도록" 잡을 수 있어서 M2 결과에서 출발해요.
- 완화는 계획서 4장 7번의 요구이고, "시비 직후 과관수 → 더 많이 씻김"이라는 시점 판단을 만들어요.
- φ를 pH에 묶으면 석회·질산화가 pH와 양이온 분포를 동시에 움직여 같은 효과를 두 번 세게 돼요. 연결은 밸런싱 결과를 보고 다시 판단해요.

## 결과

- 좋은 점: 사토 과다 시비 → EC 급등·용탈, K 과다 → Ca 밀려남, 퇴비 → CEC 증가가 전부 같은 식에서 나와요. 토양 검정(M7)에서 보여줄 교환성 양·CEC·포화도가 자연스럽게 생겨요.
- 감수하는 점: 이온 쌍별 선택 계수(Gapon, Vanselow)만큼 정확하지 않아요. 1가·2가 이온의 희석 효과(묽을수록 2가 선호)는 없어요. 염기포화도와 pH의 연동이 없어요.

## 검토한 대안

- **이온별 고정 용액 비율 유지(M2 방식)**: CEC가 효과를 내지 못해 S6이 성립하지 않아요.
- **고정 분배계수 + CEC 비례**: CEC를 넘게 붙잡을 수 있어 성질 3이 깨져요.
- **전기적 중성 모델(용액 양이온 합 = 용액 음이온 합)**: 현실에 더 가깝고 EC 근사 문제(`balancing.md` 15번)도 풀리지만, 양이온 유효도가 질산 농도에 묶여 질소 동역학과 얽히고 밸런싱이 어려워져요. 밸런싱 이후 재검토 후보로 남겨요.
- **이온 쌍별 질량작용식 연립 풀이**: 정확하지만 반복 해법이 여러 변수로 늘고, 새 판단이 생기지 않아요.
