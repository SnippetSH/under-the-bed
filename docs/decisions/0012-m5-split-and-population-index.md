# ADR-0012: M5를 M5a·M5b로 나누고, 미생물·병해충을 상대 밀도 지수로 표현

- 상태: 승인 (2026-11-19)
- 날짜: 2026-11-19

## 맥락

계획서 7장의 M5는 "개체군 동역학, 병 발생, 소독(태양열·약제), 유익균, 하우스 습도와 공기 흐름(병해)"이에요. 디렉터가 고른 목록(유해 5종, 유익 4종)에 분해균·흰가루병(2026-11-19 디렉터 결정으로 추가)까지 더하면 개체군·병해충이 12가지예요. 그중 절반은 토양 안에서, 나머지는 하우스 공기·잎에서 일어나요.

M4는 프로토타입 점검이 7차까지 갔어요. 원인은 (1) 현실 목표값을 점검 도중에 정했고, (2) 짧은 시나리오만 보다가 작기 단위 누적 문제(망간·다짐·겨울 N)를 늦게 발견했기 때문이에요. M5를 한 번에 하면 이 문제가 더 커져요.

미생물 수를 실제 단위(CFU/g)로 두면 값이 10의 몇 제곱씩 움직여서 로지스틱 식과 곡선을 다루기 어렵고, 측정 오차·표시(M7)와도 섞여요.

## 결정

1. **M5를 둘로 나눠요.** 각각 명세 승인 → 프로토타입 점검 → 최종 명세 → 구현 → 마일스톤 승인을 따로 밟아요.
   - **M5a 토양 미생물·소독**: 분해균, 질산화균(1·2단계), 근권 길항균, 균근균, 시들음병균, 역병균. 멀칭, 태양열 소독, 약제 소독, 유익균 투입, 정식 명령. 소독 → 질산화 지연·무기화 증가·망간 환원.
   - **M5b 하우스 습도·지상부 병해충**: 하우스 수증기 수지·결로·잎 젖음, 공기 흐름(측창 경로 + 유동팬), 탄저병, 잿빛곰팡이병, 흰가루병, 점박이응애와 칠레이리응애, 질소 과다 감수성, 병든 포기 제거, 점적 설치(설치 전에는 두상 관수).
   - 계획서 M5의 완료 기준 세 가지 중 "소독 후 양쪽 개체군 감소", "태양열 소독 온도·지속 시간 단조"는 M5a, "고습 시 병 발생 증가"는 M5b에서 확인해요.
2. **개체군은 셀마다 0~1의 상대 밀도 지수(`*_index`)로 둬요.** 1은 "그 무리가 그 토양에서 가질 수 있는 최대 정착 수준"이에요. 측정값(고급 검정, M7)은 이 지수를 데이터의 표시 범위로 바꿔 보여줘요.
3. **기존 시나리오에서 유익 개체군은 수용력 1 근처에 머물게** 설계하고, 활성 계수는 지수 1에서 정확히 1이 되게 해요. 그래서 M1~M4의 방향 테스트와 작기 결과가 거의 그대로 유지돼요. 이를 M5 프로토타입의 **매 차수 회귀 조건**으로 둬요.
4. **명세에 현실 목표값(참고 범위)을 처음부터 적어요.** 프로토타입 점검은 이 표를 채우는 일이에요. 출처는 `references/m5-microbes-disease.md`.

## 근거

- 디자인 원칙 1: M5a와 M5b는 판단의 축이 달라요. M5a는 "언제·어떻게 소독하고 언제 심을까, 무엇을 살릴까", M5b는 "창·팬·관수 방식으로 습도와 젖음을 어떻게 다룰까"예요. 따로 맞춰도 서로 거의 영향이 없어요(연결점은 뿌리 건강도와 질소 과다 감수성뿐).
- 점검 범위가 작아지면 차수가 줄어요. M5a를 먼저 끝내면 M5b는 습도 모델에만 집중할 수 있어요.
- 지수는 **플레이어 비공개 진짜 값**이에요(2026-11-19 디렉터 결정). 플레이어는 증상·검정(M7)·작기 리포트로만 알아요.
- 상대 지수는 0~1 범위라서 곡선·로지스틱·음수 금지 검사가 단순하고, 기존 `_index` 명명 규칙과 맞아요.

## 결과

- 좋은 점: 한 차수에 확인할 시나리오가 절반으로 줄어요. 회귀 기준이 분명해져요.
- 감수하는 점: 마일스톤 승인이 한 번 더 필요해요. CLAUDE.md의 현재 마일스톤 줄을 M5a → M5b로 두 번 바꿔요. 세이브 형식·시나리오 schema도 두 번 올라가요(M5a에서 schema 6·세이브 v7, M5b에서 schema 7·세이브 v8).
- 실제 개체 수의 크기(로그 스케일) 감각은 표시 단계(M7)에서만 나와요.

## 검토한 대안

- **M5 한 번에**: 계획서 그대로지만 11가지 무리를 한 번에 맞춰야 해요. M4보다 차수가 늘 가능성이 커요.
- **세 갈래(개체군 / 소독 / 지상부)**: 소독은 개체군 없이는 검증할 수 없어서 따로 떼면 프로토타입을 두 번 다시 만들어야 해요.
- **log10 CFU/g를 상태로**: 현실 단위지만 로지스틱 수용력·경쟁 계수가 로그 공간에서 직관적이지 않고, 측정 표시와 섞여요.
