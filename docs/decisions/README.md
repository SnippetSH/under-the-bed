# 결정 기록 (ADR)

무엇을 왜 결정하고 단순화했는지 남겨요. 한 번 승인된 ADR은 고치지 않고, 바꿀 때는 새 ADR을 써서 이전 것을 "대체됨"으로 표시해요.

## 상태 값

**제안됨** → (디렉터 검토) → **승인** 또는 **기각**. 나중에 바뀌면 **대체됨 (ADR-XXXX)**.

## 템플릿

```markdown
# ADR-XXXX: <제목>

- 상태: 제안됨
- 날짜: YYYY-MM-DD

## 맥락
## 결정
## 근거
## 결과 (좋은 점, 감수하는 점)
## 검토한 대안
```
