# M3 개요: CEC·양이온 교환, 길항, 인산 고정, 망간

- 상태: 승인 (2026-11-18, 2차 프로토타입 점검 후 개정본 재승인)
- 마일스톤: M3
- 관련 명세: [cation-exchange](cation-exchange.md), [phosphorus](phosphorus.md), [manganese](manganese.md), M2 명세 전체, [ADR-0007](../decisions/0007-acid-toxicity-and-manganese.md), [ADR-0008](../decisions/0008-cation-exchange-model.md)
- 완료 기준(계획서 7장): S5·S6 통과. 망간은 M3 범위(ADR-0007)라 S11을, 인산 고정은 새 프로세스라 S12를 함께 둬요(작업 절차 6번).

M2는 "pH가 유효도를 바꾼다"였어요. M3는 **"흙이 양분을 얼마나 붙잡고, 무엇과 무엇이 서로 밀어내는가"**예요. 토양 검정(L2)에서 보게 될 CEC, 교환성 양이온, 인산, 망간이 여기서 생겨요.

## 플레이어 판단

| 판단 | 인과관계 | 시나리오 |
| --- | --- | --- |
| K 시비량, 비료 형태 | K(또는 NH4)가 많으면 Ca·Mg가 자리에서 밀려나고(용탈↑), 뿌리 흡수에서도 경쟁에 져요 | S5 |
| 토양에 맞는 시비 방식 | CEC가 낮은 사토는 한 번에 많이 주면 못 붙잡아요. 양분·EC·pH가 크게 흔들려요 → 나눠 주기 | S6 |
| 퇴비로 흙 개량 | 부식이 CEC를 올려 완충을 키워요(숙성 퇴비는 바로, 미숙 퇴비는 분해 뒤) | 단위 테스트 |
| 시비와 관수 시점 | 비료는 녹은 채로 들어가 몇 시간에 걸쳐 붙어요. 직후 과관수하면 더 씻겨요 | 단위 테스트 |
| 인산 시비 시기와 pH | 산성·알칼리 토양에서 인산이 몇 주에 걸쳐 굳어요 | S12 |
| 망간 원인 가려내기 | 산성뿐 아니라 pH가 정상인 과습에서도 망간 과잉, 알칼리에서는 결핍. pH만으로는 몰라요 | S11 |

## M3에서 다루지 않는 것

| 요소 | M3 처리 | 도입 |
| --- | --- | --- |
| 염기포화도와 pH 연동 | 하지 않음. pH는 M2 산·염기 수지만 (ADR-0008) | 밸런싱 후 재검토 |
| S4b의 산성 토양 Ca·Mg 결핍 | M2에서 "M3 이후 재정의"로 남긴 항목. φ–pH 연동이 없어서 M3에서는 **새 기대를 추가하지 않아요**. 산성 토양의 염기 부족은 시나리오 초기값(낮은 포화도)으로 표현해요 | 연동 결정 시 |
| 증상 표현(팁번, 망간 반점 등) | 충족도·길항 배율·stress_hours까지만 | M4~M7 |
| 망간과 토양 소독 | 없음. 소독이 생길 때 산화물 환원(용액 망간 증가)으로 연결 | M5 (ADR-0007, ADR-0010) |
| Ca 흡수의 증산 의존 | 없음 | M7 (환기·습도) |
| 나트륨, 염소, 알루미늄 이온 | 없음 | - |

## 단위 규약 (M2에 추가)

| 양 | 단위 | 예 |
| --- | --- | --- |
| CEC | eq/m² | `cec_eq_per_m2` (흙 240 kg/m²에서 1 cmol/kg = 2.4 eq/m²) |
| 이온 세기, 길항 지수 | 무차원 | `k_retention_factor`, `antagonism_index` |
| Mn | 원소 기준 g/m² | `mn_g_per_m2` |

## 상태 추가

### 토양 셀

| 이름 | 의미 | 명세 |
| --- | --- | --- |
| `cec_mineral_eq_per_m2` (정적) | 광물 CEC | cation-exchange |
| `nh4_solution_N_g_per_m2`, `k_solution_g_per_m2`, `ca_solution_g_per_m2`, `mg_solution_g_per_m2`, `mn_solution_g_per_m2` | 총량 중 녹은 부분 | cation-exchange |
| `mn_g_per_m2` | 유효태 망간(교환성 + 용액) | manganese |
| `mn_oxide_g_per_m2` | 산화물 망간 (2026-11-18 개정, ADR-0010) | manganese |
| `p_fixed_g_per_m2` | 고정 인산 | phosphorus |
| `cec_eq_per_m2`, `exchange_free_site_index` (파생, 매 틱) | 전체 CEC, 빈자리 φ | cation-exchange |

M2의 `k_g_per_m2` 등은 의미 그대로 총량이에요. 교환성 양 = 총량 − 용액(파생).

### 작물

`plant_Mn_g_per_m2`. `StressFactor`에 `NutrientMn`, `ToxicityMn`을 맨 뒤에 추가. 파생값: `sufficiency_Mn`, `excess_index_Mn`, 이번 틱 길항 배율(Ca, Mg).

### 장부 추가

`Mn_in_g`, `Mn_leached_g`, `Mn_uptake_g`. 인산 고정, 망간 산화·환원, 양이온 교환은 계 안의 이동이라 장부 항이 없어요. 보존식의 P 토양 항은 `유효 + 고정`, Mn 토양 항은 `유효태 + 산화물`이에요.

## 틱 처리 순서 (M3)

```
매 틱마다:
  1. 명령 적용                    (비료·퇴비의 양이온은 총량과 용액에 함께)
  2. 하우스 환경
  3. 각 토양 셀 (행 우선):
     a. 수분
     b. 온도
     c. 통기
     d. (미생물: M5)
     e. 유기물 분해               (무기화 NH4 → 용액, 부동화 NH4 → 비례 차감)   ← M3 변경
     f. 질산화                    (NH4 비례 차감)                               ← M3 변경
     f2. 망간 산화·환원 → 양이온 교환: CEC → 빈자리 φ (Mn 세기는 pH 의존) → 평형 → 완화 ← M3
     f3. 인산 고정                                                              ← M3
     g. 석회 용해 → pH (Ca·Mg → 용액, 완충력에 광물 CEC 항)                   ← M3 변경
     h. 작물: 스트레스(+Mn 결핍·독성) → 생장 → 흡수(용액에서, Ca·Mg 길항: 능력과 수요 상한, Mn) → 뿌리 건강도·고사(Mn 반환) ← M3 변경
     i. 용탈 (용액 상태 기준, Mn 포함)                                         ← M3 변경
     j. 파생값: EC (Mn 포함)                                                    ← M3 변경
     k. 이벤트 판정
```

- 계획서 4장 "유기물 분해 → 질산화 → 양이온 교환 → pH" 순서를 따라요.
- 길항 지수는 h 시작 시점의 용액 상태로 한 번 계산해요.
- 기존 원칙 그대로: 이동량은 원천 풀로 제한, 1차 반응은 `풀 × min(1, 속도 × 계수)`.

## 명령

새 명령은 없어요. 황산망간은 `[[fertilizer]]` 데이터로 추가해요(`AddFertilizer`). `variant` 순서는 M2 그대로예요.

## 데이터 배치

### `data/params.toml` (schema_version 4)

추가: `[cation_exchange]`, `[antagonism]`, `[phosphorus]`, `[manganese]`, `[ions] mn_g_per_eq`, `[crop]`의 Mn 키 4개, `[[fertilizer]]`·`[[compost]]`의 `mn_g_per_kg`, 비료 `manganese_sulfate`.
삭제: `soil_chemistry.k_solution_fraction`, `ca_solution_fraction`, `mg_solution_fraction`, `leaching.nh4_solution_fraction` (`[leaching]` 테이블이 비면 테이블도 삭제).

### 시나리오 TOML (schema_version 4)

```toml
[soil]       # M2 항목 + 아래
cec_mineral_eq_per_m2 = 25.0        # 양토 약 10 cmol/kg (부식 몫 별도)
mn_g_per_m2 = 5.0
mn_oxide_g_per_m2 = 100.0         # 2026-11-18 개정 (ADR-0010)
p_fixed_g_per_m2 = 150.0            # 유효 25 g의 약 6배 (적정 pH 평형)
base_buffer_eq_per_m2_per_pH = 1.25 # M3부터 "CEC 밖 완충". 5.0 − 0.15 × 25
```

용액 상태는 시나리오에 적지 않고, 월드 생성 시 **평형값으로 시작**해요(완화 없이 한 번에).

### 시나리오 이행 (M1·M2 시나리오)

모든 M1·M2 시나리오를 schema 4로 올리고 위 5줄을 넣어요. `base_buffer`를 1.25로 줄여 **총 완충력을 M2와 같게** 유지해요. 시작 시점 용액 비율도 M2와 거의 같아서(세기 w를 그렇게 잡음) 결과 변화는 M3 효과(교환 완화, 인산 고정, 망간)에서만 와요. 방향 테스트(S1~S4b, S8~S10)는 그대로 통과해야 해요. 수치 변화는 프로토타입 점검 결과에 적어요.

## 시나리오 테스트 (M3)

작물이 있는 시나리오는 별도 표기가 없으면 M2처럼 매일 8시에 6 mm 관수해요. 기준 토양은 위 이행 값과 같아요.

| ID | 비교 | 기대 방향 | 기간 |
| --- | --- | --- | --- |
| **S5** | `s5_standard`(황산칼륨 20 g/m²) 대 `s5_k_excess`(60 g/m²), 각각 0·7·14일 | 과다 쪽: ① 작물 Ca 흡수 누계(`Ca_uptake_g`)가 적다 ② 최종 Ca 충족도가 낮다 ③ 최종 K 충족도는 같거나 높다(전체 흡수 실패가 아님) ④ Ca 용탈 누계가 크다(밀려남) | 21일 |
| **S6** | `s6_loam`(광물 CEC 25) 대 `s6_sand`(광물 CEC 1), 같은 처방(0·7·14일에 황산암모늄·황산칼륨·질산칼슘 각 30 g/m²) | 사토 쪽: 시간별 하우스 평균의 **변동폭(최대 − 최소)**이 pH, 용액 K, EC 모두 크다. K 용탈 누계도 크다 | 21일 |
| S11 | `s11_neutral` · `s11_acid` · `s11_wet` · `s11_alkaline` ([manganese](manganese.md)) | 평균 용액 Mn: acid > neutral, wet > neutral, neutral > alkaline. 최종 체내 Mn 비율 같은 순서. alkaline의 Mn 충족도 < neutral. **석회 조건**(2026-11-18 추가): M2 `s9_lime` 대 `s9_none`에서 석회 쪽 14일 평균 용액 Mn, 최종 유효태 Mn, 최종 체내 Mn 비율이 작다 | 21일 (석회 조건 14일) |
| S12 | `s12_neutral`(pH 6.5) · `s12_acid`(5.0) · `s12_alkaline`(8.0), 과인산석회 같은 양, 작물 없음 ([phosphorus](phosphorus.md)) | 28일째 유효 P: neutral > acid, neutral > alkaline. 세 토양 모두 1일째 > 28일째 | 28일 |
| 회귀 | M1 S1~S3, M2 S4·S4b·S8·S9·S10 | 기존 방향 그대로. 단 S4 보조 조건은 토양 P 총량(유효 + 고정) 비교 (디렉터 결정 2번) | 각 기간 |
| 보존 | 위 전부 + 극한(황산칼륨 100배, 사토에 석회 100배, 황산망간 100배, 광물 CEC 0.01, 관수 0) | 물·N·P·K·Ca·Mg·Mn·S·C 보존(토양 + 작물), 모든 풀 ≥ 0, 용액 ≤ 총량, 0 ≤ φ ≤ 1, NaN 없음 | 매 틱 |

- S6의 두 토양은 **CEC 관련 값만** 달라요: 광물 CEC, `base_buffer`(사토 0.5), 양이온 총량(같은 포화도가 되도록 CEC 비율만큼 줄임: 사토 CEC 6.4 / 양토 30.4), 산화물 망간(유효태와 같은 비율, 100 → 21. 사토는 망간 총량도 적어요. 3차 점검 후 추가). 수분·유기물·질소·인산·작물은 같아요. 차이가 CEC에서 온다는 걸 보여주려는 설계예요.
- S5의 과다 용량은 **EC 때문에 생장이 꺾이는 효과가 길항을 가리지 않도록**(과다 쪽 최대 EC가 염류 곡선 문턱 2.0을 크게 넘지 않게) 프로토타입 점검에서 60 g/m²로 정했어요(최대 EC 2.50 dS/m). 조건 ③이 "염류로 모든 흡수가 줄어서"가 아님을 확인하는 장치예요.
- 측정 정의 (2026-11-18 프로토타입 점검에서 명시):
  - "평균"(S11)은 0틱을 포함한 전체 기간의 **시간별 하우스 평균**의 평균이에요.
  - "변동폭"(S6)은 시간별 하우스 평균의 최대 − 최소예요.
  - "1일째"(S12)는 24틱 시점, "N일째"는 N × 24틱 시점이에요.
  - 장부 값(`*_uptake_g`, `*_leached_g`)은 하우스 전체 합계예요.

## 디렉터 결정 (2026-11-18)

1. **S5의 "팁번 증상"**: M3의 S5는 위 ①~④(Ca 흡수·충족도·용탈)로 판정해요. "팁번"은 증상 매핑(M4~M7) 때 `Ca 충족도 + 길항 배율`에서 만들어요.
2. **S4 보조 조건 변경**: `p_alk >= p_opt`를 **토양 P 총량(유효 + 고정)** 비교로 바꿔요. 원래 뜻("총량이 충분해도")을 유지하는 변경이에요.
3. **길항에 NH4 포함**: 길항 지수는 (K + NH4) / (Ca + Mg)예요. Ca 결핍의 원인이 K인지 NH4인지 측정으로 가려야 하는 판단을 만들어요.
4. **M1·M2 시나리오 이행**: schema 4로 올리면서 `base_buffer` 5.0 → 1.25(총 완충력 유지)로 바꿔요.
5. **길항은 수요 상한에도** (2차 점검 후): K 과다에서 체내 Ca가 늘 상한까지 차서 길항이 결과에 남지 않았어요. 길항 배율을 흡수 능력과 Ca·Mg 수요 상한 양쪽에 곱해요([cation-exchange](cation-exchange.md)).
6. **망간 산화물 풀과 pH 의존 흡착력** (2차 점검 후, [ADR-0010](../decisions/0010-manganese-oxide-pool.md)): 석회가 망간 독성을 오히려 키우던 문제를 현실의 원리(pH 상승 → Mn2+ 산화·침전, 탈양성자화로 특이 흡착 증가)로 고쳐요. 이동성 곡선은 삭제해요.
7. **3차 점검 후** (2026-11-18): S5-② 판정 기준은 그대로 두고 길항 곡선을 기준 지수(약 0.2)에서 꺾이게 다시 잡아요(E2). 망간 흡착 세기 곡선을 pH 5.0~5.3에서 가파르게(H), 석회 조건에 체내 Mn 비율 추가. 사토 산화물 망간 축소. pH가 기준과 다른 시나리오가 시작 직후 평형 쪽으로 흘러가는 것은 그대로 둬요(S12 인산과 같은 방식, 판마다 평형 시작은 ADR-0009 밭 생성에서).
8. **4차 점검 후** (2026-11-18): 길항이 수요 상한을 깎는 배율에 하한 0.6(`antagonism.min_demand_factor`)을 둬요. S6 처방(황산암모늄 등 30 g/m² × 3회)은 그대로 두고 밸런싱 메모(`balancing.md` 20번)에 남겨요. S5의 "최대 EC가 염류 문턱을 크게 넘지 않게"는 프로토타입 확인용이고 정식 테스트 조건에는 넣지 않아요(4차 2.502 dS/m를 충족으로 봄).
