# M5 개요: 미생물·병해 (M5a 토양 미생물·소독 / M5b 하우스 습도·지상부 병해충)

- 상태: 승인 (2026-11-19, M5a 범위와 13장 사전 작업. M5b 부분은 방향 초안이라 M5a 승인 뒤 다시 승인). 디렉터 결정 반영(분할, 분해균·흰가루병 추가, Plant 명령, 필름 3종, 약제 2종, 진짜 값 비공개, 점적은 설치 장비)
- M5a 최종안 승인 (2026-11-19, 프로토타입 1~4차 반영): 5장 "프로토타입 4차 값", 11장 데이터, 12장 결정 16~21, 14.1 진행 기록, **14.2 최종 승인 요청 목록**, [ADR-0013](../decisions/0013-m5a-deep-soil-and-cell-variation.md)
- 마일스톤: M5 (분할 제안: M5a, M5b — [ADR-0012](../decisions/0012-m5-split-and-population-index.md))
- 관련 명세: [soil-microbes](soil-microbes.md), [disinfection](disinfection.md) (M5a), [house-humidity](house-humidity.md), [foliar-disease](foliar-disease.md) (M5b), M1~M4 명세 전체
- 관련 ADR: [ADR-0006](../decisions/0006-off-season-and-disinfection.md)(태양열 소독), [ADR-0010](../decisions/0010-manganese-oxide-pool.md)(소독 → 망간 환원), [ADR-0011](../decisions/0011-house-climate-in-m4.md) 결정 6(습도·공기 흐름은 M5), [ADR-0012](../decisions/0012-m5-split-and-population-index.md)(분할, 상대 지수)
- 참고 자료: [references/m5-soil-disinfection.md](../../references/m5-soil-disinfection.md), [references/m5-foliar-humidity.md](../../references/m5-foliar-humidity.md), [references/m5-microbes-disease.md](../../references/m5-microbes-disease.md)(1차)
- 완료 기준(계획서 7장): 소독 후 양쪽(유익·유해) 개체군 감소, 고습 시 병 발생 증가 재현, 태양열 소독은 토양 온도·지속 시간이 클수록 사멸량 증가

M4까지 흙 속 생물은 "속도 곡선"에 숨어 있었어요. M5는 **흙과 하우스에 사는 것들이 늘고 줄며, 그것을 플레이어가 죽이고 살리는 판단**을 만들어요. 소독은 병원균만 골라 죽이지 못하고, 습도를 낮추면 응애가 늘어요.

## 1. M5를 둘로 나누는 제안

| 부분 | 내용 | 완료 기준 | 명세 |
| --- | --- | --- | --- |
| **M5a 토양 미생물·소독** | 개체군 7종(분해균, 질산화균 1·2단계, 근권 길항균, 균근균, 시들음병균, 역병균), 멀칭, 태양열·약제 소독, 유익균 투입, 정식 명령, 토양 병해 → 뿌리 건강도 | 소독 후 유익·유해 모두 감소, 태양열 소독 사멸량이 온도·기간에 단조 증가, 소독 직후 정식 함정(NH4·NO2 축적) 재현, 1작기 회귀 유지 | soil-microbes, disinfection |

- **2026-11-19 디렉터 결정: 나눠요.** M5a를 먼저 끝내고(마일스톤 승인), M5b 명세를 확정·승인한 뒤 들어가요. 이 문서의 M5b 부분과 M5b 명세 두 개는 **방향을 미리 보여주는 초안**이고, M5a 승인 뒤에 한 번 더 다듬어 승인받아요.

### 추가한 이유 (2026-11-19 디렉터 결정: 둘 다 추가)

1. **분해균**: 계획서 4장에 이미 있는 개체군이고, organic-matter의 `분해균계수` 자리가 비어 있어요. 무엇보다 **"소독 → 죽은 미생물의 질소가 암모늄으로 풀림 + 질산화균은 죽어 있음 → 암모늄 축적"** 함정(ADR-0006, 계획서 6장 커리어 모드)의 절반을 만들어요. 빼면 소독 함정이 질산화 지연만으로 약해져요.
2. **흰가루병 (Podosphaera)**: 국내 촉성 딸기 하우스에서 잿빛곰팡이병과 함께 가장 흔한 지상부 병이에요. 조건이 잿빛곰팡이병과 **반대쪽에 걸쳐 있어** 판단이 생겨요. 다습한 공기를 좋아하지만 **잎의 물방울(결로·두상 관수)에는 오히려 억제**되고, 광이 약하고 잎이 빽빽하면 늘어요(피복 겹수를 늘리면 어두워지는 M4 판단과 연결). "무조건 말리면 된다"를 깨요. M5b에 1종 추가(포자 압력 1개, 감염 1개)예요. 그래서 M5b의 습도 판단은 "잿빛곰팡이(젖음) 대 흰가루병(습한 공기·마른 잎·약광) 대 응애(건조)" 세 축이에요.

다루지 않기로 한 후보: 탈질균(denitrification 곡선 유지, 판단을 새로 만들지 않음), 망간 산화균(manganese 곡선 유지, ADR-0010), 뿌리혹선충(시들음병과 상승 작용이 있지만 범위 대비 판단이 겹침, 커리어 모드 연작 장해(M8) 후보).

## 7. 틱 처리 순서 (M5)

```
매 틱마다:
  1. 명령 적용 (M5a: SetMulch, ApplyDisinfectant, AddInoculant, Plant / M5b: SetFan, RemovePlant, ReleasePredators, InstallDrip)
  2. 하우스 환경: 피복·창 → 기온·난방 → 이동 평균, 바깥 CO2
                 (M5b) 공기 흐름 지수
  3. 각 토양 셀 (행 우선):
     a. 수분 (M5a: 멀칭 증발 계수)  b. 온도 (M5a: 멀칭 지온 이득)  c. 통기
     d. 미생물 (M5a, soil-microbes):
        d1. 약제 잔류: 활성화·분해·필름 보존
        d2. 개체군 갱신: 적합도 → 로지스틱 성장·경쟁 → 자연 사멸 + 열 사멸 + 약제 사멸 → 유입
        d3. 소독 사멸분 → 무기화 증가(N flush), 망간 산화물 환원
     e. 유기물 분해 (× 분해균 활성)
     f. 질산화 (1단계 × 1단계균 활성, 2단계 × 2단계균 활성)
     f1. 탈질  f2. 망간 산화·환원 → 양이온 교환  f3. 인산 고정 (× 균근균 가용화)
     g. 석회 → pH
     h. 작물:
        h0. 저온 피해
        h1. 생물계절  h2. 스트레스 (M5a: 균근균 완화)  h3. 생장·분배 (M5b: 응애 광합성 감소)
        h4. 과실 (M5b: 잿빛곰팡이·탄저 과실 손실)
        h5. 흡수
        h6. 감염 진행 (M5a: 시들음병·역병 / M5b: 탄저병) → 뿌리 건강도(손상 항 추가: 병, 약제 잔류)·고사 → 낙엽
        h7. (M5b) 응애·칠레이리응애 갱신
     i. 용탈  j. 파생값  k. 이벤트 판정 (DiseaseOnset 추가)
  4. 하우스 CO2 갱신
     (M5b) 하우스 수증기 갱신(증산·증발·환기·결로) → 상대습도 → 잎 젖음 → 잿빛곰팡이 포자 압력
```

- M5a의 미생물 단계(d)는 같은 틱의 토양 온도·수분·통기를 써요. 개체군은 **단계 시작 값으로 한꺼번에** 갱신해요(무리 순서에 결과가 의존하지 않게).
- M5b의 습도는 셀 계산이 끝난 뒤 하우스 단계에서 갱신하고, 병해는 **틱 시작 때의 습도·젖음**을 써요(CO2와 같은 방식).

## 10. 1작기 회귀 게이트 (M5 내내)

M4 교훈: 짧은 시나리오만 보면 작기 단위 누적 문제를 늦게 발견해요. M5는 **모든 프로토타입 차수와 구현 단계에서** 아래를 같이 돌려요.

```powershell
.venv\Scripts\python.exe tools/season_regression.py --params <차수의 params.toml>
```

- 대상: M4 `season_*` 7개(263일). 기준값은 M4 최종 결과(`tests/baselines/m4_season_summary.json`).
- 허용 오차: 누적 수확 ±3%, 월별 ±5%(50 g/m² 미만인 달 제외), 평균 당도·경도 ±3%, 첫 수확 ±3일.
- M5a는 기존 시나리오에 병원균이 없고 유익균이 1에서 시작하므로 **통과가 기본**이에요. 벗어나면 원인(대개 유익균이 수용력 아래로 내려감)을 차수 보고에 적고, 고칠지·기준을 바꿀지 디렉터 결정을 받아요.
- 차수 보고는 "목표값 표(5장) 현재 값 / 1작기 회귀 표 / 시나리오 확인 행" 세 표로 해요.
- 값 조정은 `tools/param_sweep.py`로 후보를 한 번에 돌려 고르고, 고른 값만 보고해요.

## 11. 데이터 배치 (M5a)

### `data/params.toml` (schema_version 6)

추가: `[microbes]`(공통), `[microbes.<id>]` 7개(곡선·속도·경쟁 계수), `[disinfection]`, `[[mulch]]` 3개(투명·흑색·백색), `[[disinfectant]]` 2개(다조멧·클로로피크린), `[[inoculant]]`, `[root_damage]`에 `disease`·`fumigant` 곡선, `[[seedling_grade]]`에 (M5b) 잠복 감염 키. 정확한 키는 soil-microbes·disinfection 명세.

(최종안, 구현 기준) 키 배치:
- `[microbes]` 공통: `capacity_floor_index`, 활동 곡선 3개, `antagonist_protection_factor`, 균근균 계수 3개, `moist_heat_curve`, 수용력 곡선 4개(`decomposer_food_curve`, `antagonist_food_curve`, `mycorrhiza_host_curve`, `mycorrhiza_p_curve`), `pathogen_spread_index`, `susceptibility_spread_index`.
- `[microbes.<id>]`: `growth_rate_per_hour`, `temp_curve`, `moisture_curve`, `ph_curve`, `o2_curve`(쓰지 않는 축도 `[[0,1],[14,1]]`로 명시), `base_death_rate_per_hour`, `heat_kill_curve`, `immigration_rate_per_hour`, `competition`(인라인 표 `{ 무리 id = α }`, 적지 않은 무리 0, 자기 자신·모르는 id는 오류). 병원균만 `saprophytic_capacity_index`, `host_capacity_index`(다른 무리에 쓰면 오류).
- `[soil_disease.fusarium]`, `[soil_disease.phytophthora]`, `[disinfection]`, `[[mulch]]`, `[[disinfectant]]`(`kill_rate_per_hour`는 7개 무리 전부 필수), `[[inoculant]]`(`index_gain_per_g_per_m2`는 일부만 적어도 됨, 나머지 0).
- `[soil_temperature]`에 `deep_coupling_fraction`, `deep_relax_rate_per_hour`.
- 바뀐 M1 값: `soil_temperature.relax_rate_per_hour` 0.08, `nitrification.step2_rate_per_hour` 0.2.
- 일정 명령: `set_mulch`(`mulch`, 선택 `area`), `apply_disinfectant`(`disinfectant`, `g_per_m2`, 선택 `area`), `add_inoculant`(`inoculant`, `g_per_m2`, 선택 `area`), `plant`(`seedling_grade`, `plants_per_m2`, `area` 없음). 멀칭 id `"none"`은 걷기 예약어라 데이터 id로 못 써요.
- schema 5 params·시나리오는 `UnsupportedVersion`으로 거부해요.

### 시나리오 TOML (schema_version 6)

```toml
[microbes]          # 필수. 모든 셀의 시작 지수 (0~1)
decomposer = 1.0
nitrifier_aob = 1.0
nitrifier_nob = 1.0
antagonist = 0.5
mycorrhiza = 0.1
fusarium = 0.0
phytophthora = 0.0
```

- **필수 섹션**이에요(M4처럼 기본값으로 숨기지 않아요). M1~M4 시나리오는 위 기본 줄을 그대로 넣어 schema 6으로 올려요.
- 작물이 없는 시나리오에서 `Plant` 명령으로 나중에 심을 수 있어요. `[crop]`이 있으면 지금처럼 tick 0 정식이에요.

### 세이브 형식 v7

셀에 개체군 지수 7개, 멀칭 id, 약제 잔류, 작물에 감염 지수 2개. 하우스 상태는 M5a에서 변화 없음.

(최종안, 구현 기준) v7 = M5a 사전 작업(저장 탄수화물, RGR 이동 평균 등) + 위 내용 + 셀 `deep_soil_temp_degC`, 셀 `fumigant_residue_index`(약제별 배열), 셀 `disinfection_kill_index`(파생, 7개), 작물 `infection_index`·`disease_onset_reported`(각 2개)·`disease_susceptibility_factor`, 장부 `N_flush_g`·`Mn_flush_g`·`disinfectant_applied_g`(약제별)·`inoculant_applied_g`, 새 명령 4개, **disease 난수 스트림 상태**(biology 스트림 다음), 새 파라미터 전부. 저장된 대기 중 명령은 타일을 읽은 뒤 검증해요(대기 중 `Plant`를 저장된 작물에 대해 확인하려고).

- 모델 원인: N 흡수 요구량이 `목표 × 1.2 − 체내 N`이라 상한에서 **딱 멈춰요**(`n_luxury_uptake_ratio`). 겨울엔 생장이 느려 요구량이 거의 안 늘고, 표준 처방의 겨울 웃거름도 생장보다 많아서 **표준과 과다가 12~4월 내내 같은 값(0.20)**이에요. 차이는 흙에만 남아요(토양 NO3 약 15배).
- 그래서 지금 체내 N 비율로 감수성을 정하면 겨울 잿빛곰팡이·흰가루병에서 표준과 과다가 구분되지 않아요. M4의 화아분화 질소 곡선도 겨울엔 두 처방이 같은 값을 받아요(balancing 27).
- 월별 N 흐름(표준, 하우스 평균 g N/m²): 12~1월 흡수 1.2~1.3, 수확 반출 1.2, 체내 N −0.8/월. 체내 N은 줄지만 **영양 기관 건물도 같이 줄어** 비율은 1.2에 그대로예요. 흡수 능력이 요구량보다 커서 매 틱 상한까지 다시 채워져요(공급 제한이 아니라 상한 제한).

**현실 확인 (2026-11-19 2차 조사, [references/m5-foliar-humidity.md](../../references/m5-foliar-humidity.md) 6절)**

- 표준 관리에서 딸기 체내 N은 겨울에 **상한에 붙지 않고 내려가요.** 엽 N 적정은 첫 수확기 3.0~3.5%, 중·후반 2.8~3.0%(후반에 3.0% 넘으면 "높음"). 엽병 즙액 질산은 11월 800~900 ppm → 2~4월 200~500 ppm으로 떨어져요(과실이 잎의 N을 끌어감).
- 겨울에도 높게 머무는 건 **과다 시비**일 때예요. 국내 농가는 과다 시비가 흔해요(충남 435농가 토양 EC 평균 2.28 dS/m, 적정 1.2 미만, 적정 범위 35%).
- 지금 모델의 상한은 0.028 × 1.2 = 3.36%로, 중·후반 기준 "높음"이에요. 모델의 겨울 영양 기관 N 농도는 약 3.6~3.7%(과실 N 포함 근사)예요.
- 병해 문헌은 거의 모두 **공급 쪽 지표**(양액 N 농도, 시비량, 토양 N)를 써요. 엽 N %를 쓴 딸기 연구는 하나(최적보다 30% 이상 높으면 과실의 잿빛곰팡이 저항성 저하)예요. 효과 크기는 해마다 불안정하고(3년 중 1년만 증가), 토마토에서는 N이 너무 적어도 감수성이 오르는 U자 모양이에요.

**원인 분석 (모델)**

1. **흡수에 지온 영향이 없어요.** `capacity_N = 유효 N × min(1, 흡수 속도 × 뿌리 × 뿌리 건강도) × 수분 × 염류 × 활착`에 지온 항이 없어요(`crop.cpp`에서 확인). 현실에서는 겨울 근권 온도(약 12~16 °C)에서 뿌리 흡수가 크게 줄어, 과실이 끌어가는 N을 다 채우지 못해 체내 N이 내려가요.
2. **사치 흡수 상한이 계단식이에요.** `demand_N = 요구량 × 1.2 − 체내 N`이라 공급이 조금만 남아도 정확히 1.2까지 채우고, 그 이상은 0이에요. 그래서 공급이 15배 차이 나도 체내 지표는 같아요.
3. 결과적으로 표준 처방이 실제보다 "겨울 과다 쪽"에 있고, 과다 처방과 체내 지표로 구분되지 않아요. M4의 화아분화 질소 곡선도 겨울엔 같은 값을 받아요(balancing 27의 원인).

**제안 (질문으로 결정)**

- 병해 감수성 지표는 문헌처럼 **공급 쪽(근권 토양 무기 N 또는 EC, 2주 이동 평균)**으로 해요(M5b). 작물 상한 문제와 무관하게 표준과 과다가 갈려요(겨울 토양 NO3 약 15배 차이).
- 작물 쪽 원인(1·2번)은 M4 결과(1작기 기준값)를 바꾸는 구조 변경이라 **따로 처리**해요. 후보: (가) 흡수에 근권 온도 곡선, (나) 계단식 상한 대신 체내 N 비율에 따라 흡수가 서서히 줄어드는 곡선. 둘 다 넣으면 표준은 겨울에 2.8~3.0% 쪽으로 내려가고 과다는 높게 남을 것으로 예상해요(프로토타입에서 확인).
