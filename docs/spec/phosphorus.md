# 인산 고정

- 상태: 승인 (2026-11-18)
- 마일스톤: M3
- 관련: [m3-overview](m3-overview.md), [soil-chemistry](soil-chemistry.md)

## 목적

M2의 인산은 "pH 유효도 곡선"으로만 순간적으로 줄었어요. M3는 **시간에 따라 굳는(고정) 인산**을 넣어요.

- 인산을 한꺼번에 많이 넣어도 산성(Fe·Al)·알칼리(Ca) 토양에서는 몇 주에 걸쳐 굳어서 효과가 사라져요. → 판단: **pH 먼저 맞추기, 나눠 주기, 정식 직전 시비**
- 굳은 인산은 아주 천천히만 풀려서, 작기를 거듭하면 "총 인산은 많은데 결핍"인 흙이 돼요(커리어 모드 M8의 인산 과다 축적과 연결).

## 상태 변수 (셀)

| 이름 | 의미 | 단위 |
| --- | --- | --- |
| `p_g_per_m2` (M2) | **유효 인산 풀**. 의미 그대로(흡수·용탈 대상) | g P/m² |
| `p_fixed_g_per_m2` (신규) | 고정된 인산. 흡수·용탈되지 않음 | g P/m² |

토양 P 총량 = `p_g_per_m2 + p_fixed_g_per_m2`.

## 파라미터 (`[phosphorus]`)

| 키 | 의미 | 단위 | 초기값 | 출처 |
| --- | --- | --- | --- | --- |
| `fixation_rate_per_hour` | 유효 → 고정 최대 시간당 비율 | 1/h | 0.0015 | 게임용 임의값 (pH 곡선 1에서 반감기 약 19일) |
| `fixation_ph_curve` | x = pH, y = 고정 속도 배율. 산성(Fe·Al)·알칼리(Ca)에서 큼 | - | `[[4.5,1.0],[5.5,0.6],[6.3,0.2],[6.8,0.2],[7.5,0.6],[8.5,1.0]]` | 게임용 임의값 (일반 유효도 도표 모양) |
| `release_rate_per_hour` | 고정 → 유효 시간당 비율 (pH 무관) | 1/h | 0.00005 | 게임용 임의값 (반감기 약 1.6년) |

- 적정 pH(곡선 0.2)에서 평형 비 `고정 / 유효 = 0.0015 × 0.2 / 0.00005 = 6`. 시나리오 초기값은 이 근처로 잡아요(유효 25 g → 고정 150 g).

## 프로세스 (셀 단계 f3, 양이온 교환 다음)

```
fixed    = p × min(1, fixation_rate × fixation_ph_curve(pH))
released = p_fixed × min(1, release_rate)
p       += released − fixed
p_fixed += fixed − released
```

- 두 이동량은 같은 틱 시작 값으로 계산해요(순서 의존 없음). 각자 원천 풀로 제한돼서 음수가 안 돼요.
- M2의 `p_solution_fraction`, `availability.p_ph_curve`는 그대로예요. 곡선은 "지금 녹아 있는 인산이 뿌리에 얼마나 쓸모 있는가"(순간), 고정은 "유효 풀 자체가 줄어드는 것"(시간)으로 역할을 나눠요.
- 방향: 알칼리·산성 토양에서 유효 풀이 몇 주에 걸쳐 줄고, 적정 pH에서는 거의 그대로예요.

## 보존·불변 조건

- P: `유효 + 고정 + 작물 체내 = 초기(유효 + 고정) + P_in − P_leached`. 고정은 계 안의 이동이라 장부 항이 없어요.
- 두 풀 ≥ 0.

## 테스트 (단위)

| 조건 | 기대 |
| --- | --- |
| pH 6.5 대 5.0 대 8.0, 같은 유효 P | 고정량 5.0·8.0 > 6.5 |
| 고정 0, 유효 0 | 변화 없음, NaN 없음 |
| 평형 비(6)에서 시작, pH 적정 | 유효 풀이 거의 변하지 않음 (1주에 ±5% 안) |
| 고정 속도 극단(곡선 × 속도 ≥ 1) | 유효 풀이 0이 되고 음수가 아님 |
| 총량 | 유효 + 고정이 흡수·용탈 없이 보존 |

## 시나리오 (S12, [m3-overview](m3-overview.md))

과인산석회를 같은 양 넣은 pH 6.5·5.0·8.0 토양(작물 없음, 28일): 28일 뒤 남은 유효 인산이 6.5 > 5.0, 6.5 > 8.0. 세 토양 모두 1일째보다 28일째 유효 인산이 적어요.

## 단순화와 비목표

- 흡착 포화(고정 자리가 차면 덜 굳음)는 없어요. 1차 반응이에요.
- 유기물이 고정을 줄이는 효과, 유기태 인산의 무기화는 없어요(퇴비 P는 M2처럼 투입 즉시 유효 풀).
- 고정 풀 하나에 Fe·Al·Ca 인산을 모두 넣어요. 형태별 용해도 차이는 없어요.
- 균근, 근권 산 분비로 인한 인산 용해는 없어요.
