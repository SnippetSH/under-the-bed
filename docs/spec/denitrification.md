# 탈질

- 상태: 승인 (2026-11-18)
- 마일스톤: M4
- 관련: [m4-overview](m4-overview.md), [nitrogen](nitrogen.md), [aeration](aeration.md), [soil-chemistry](soil-chemistry.md), 계획서 4장 6번

## 목적

과습한 흙에서 질산이 기체로 날아가는 손실을 만들어요.

- 물을 많이 주면 용탈(아래로 씻김)뿐 아니라 탈질(공기로 날아감)로도 질소를 잃어요. 과습의 비용이 커져요.
- 질소 장부의 `N_gas_g`가 처음으로 0이 아니게 돼요. "준 질소가 어디로 갔는가"를 작기 리포트(M7)에서 보여줄 수 있어요.

## 상태 변수

새 상태는 없어요. `no3_N_g_per_m2`가 줄고 장부 `N_gas_g`가 늘어요.

## 파라미터 (`[denitrification]`, 모두 게임용 임의값)

| 키 | 의미 | 초기값 | 비고 |
| --- | --- | --- | --- |
| `rate_per_hour` | 최대 시간당 NO3 손실 비율 | 0.004 | 최적 조건 반감기 약 7일 |
| `o2_curve` | x = aeration_index, y = 배율. 산소가 없을수록 큼 | `[[0,1],[0.2,0.6],[0.4,0.15],[0.5,0],[1,0]]` | 과습 손상 곡선과 같은 구간 |
| `temp_curve` | x = 토양 온도 °C | `[[0,0],[10,0.3],[25,1],[35,1],[45,0.5]]` | |
| `carbon_curve` | x = 이분해성 유기 C g/m², y = 배율 | `[[0,0.1],[50,0.6],[200,1]]` | 탈질균의 먹이. 미숙 퇴비 + 과습이면 커요 |
| `H_eq_per_eq_N` | 탈질된 N 1 eq당 생기는 H+ | -1.0 | 화학량론: 탈질은 H+를 소비해 pH를 올려요(음수 = 염기) |

## 프로세스 (셀 단계 f1, 질산화 다음, 양이온 교환 앞)

```
lost = no3 × min(1, rate × o2_curve(aeration) × temp_curve(soil_temp) × carbon_curve(labile_C))
no3 −= lost
ledger.N_gas_g += lost
acid_H_eq_this_tick += lost / no3_N_g_per_eq × H_eq_per_eq_N
```

- 방향: 통기가 충분하면(0.5 이상) 0이에요. 과습·따뜻함·유기물이 겹칠수록 커요.
- NO3는 전부 용액이라 교환 상태와 무관해요.

## 보존·불변 조건

- N: `토양 + 체내 = 초기 + in − leached − gas − harvested`. 탈질은 `gas` 항이에요.
- NO3 ≥ 0.

## 테스트 (단위)

| 조건 | 기대 |
| --- | --- |
| 통기 0.8 | 손실 0 |
| 통기 0.1 대 0.3 | 0.1 쪽 손실이 큼 |
| 같은 과습, 이분해성 C 0 대 200 | 200 쪽 손실이 큼 |
| 손실 1 eq | pH 단계에 −1 eq(염기)가 들어감 |
| 속도 × 곡선 ≥ 1 | NO3가 0이 되고 음수가 아님, 장부와 일치 |

## 시나리오 (S13, [m4-overview](m4-overview.md))

`s13_proper`(M2 S8 적정 조건) 대 `s13_waterlogged`(S8 과습 조건), 14일: 과습 쪽 `N_gas_g`가 크고, 적정 쪽은 0에 가까워요.

## 단순화와 비목표

- N2O·N2 구분은 없어요. 전부 `N_gas`예요.
- 암모니아 휘산과 시설 가스 장해는 M7이에요.
- 탈질균 개체군은 M5에서도 따로 두지 않고 곡선에 둬요(M5 명세에서 다시 판단).
