# 양이온 교환: CEC, 교환성·용액 양이온, 흡수 길항

- 상태: 승인 (2026-11-18, 2차 프로토타입 점검 후 개정본 재승인)
- 마일스톤: M3
- 관련: [m3-overview](m3-overview.md), [soil-chemistry](soil-chemistry.md), [strawberry-minimal](strawberry-minimal.md), [manganese](manganese.md), [ADR-0008](../decisions/0008-cation-exchange-model.md)

## 목적

M2에서 고정 비율로 나눴던 "흙에 붙은 양이온 ↔ 녹은 양이온"을 **CEC와 경쟁**으로 바꿔요.

- 같은 처방이라도 CEC가 낮은 흙(사토)은 양분과 pH가 크게 흔들려요. 한 번에 많이 주면 자리가 모자라 녹은 채로 남고, EC가 튀고, 물과 함께 씻겨 나가요 (S6). → 판단: **나눠 주기, 퇴비로 CEC 올리기**
- 칼륨(또는 암모늄)을 과하게 넣으면 Ca·Mg가 자리에서 밀려나 용탈 위험이 커지고, 뿌리에서도 Ca·Mg 흡수가 경쟁에 밀려요 (S5). → 판단: **K 시비량, 비료 형태, 토양 검정의 K/(Ca+Mg) 비**
- 비료는 처음에 용액으로 들어가고 몇 시간에 걸쳐 자리에 붙어요. 시비 직후 과관수하면 더 많이 씻겨요. → 판단: **시비와 관수 시점**

## 상태 변수 (셀)

M2의 원소 풀(`k_g_per_m2` 등)은 의미 그대로 **총량(흙에 붙은 것 + 녹은 것)**이에요. M3는 그중 **녹은 부분**을 상태로 따로 들고, 붙은 부분은 차이로 계산해요.

| 이름 | 의미 | 단위 | 범위 |
| --- | --- | --- | --- |
| `nh4_solution_N_g_per_m2` | NH4+ 중 녹은 것 | g N/m² | 0 ~ `nh4_N_g_per_m2` |
| `k_solution_g_per_m2`, `ca_solution_g_per_m2`, `mg_solution_g_per_m2` | K·Ca·Mg 중 녹은 것 | g/m² | 0 ~ 총량 |
| `mn_solution_g_per_m2` | Mn 중 녹은 것 ([manganese](manganese.md)) | g/m² | 0 ~ `mn_g_per_m2` |
| `cec_mineral_eq_per_m2` (정적) | 광물(점토) CEC. 시나리오 `[soil]` | eq/m² | > 0 |
| `cec_eq_per_m2` (파생, 매 틱) | 전체 CEC = 광물 + 유기물 기여 | eq/m² | > 0 |
| `exchange_free_site_index` (파생, 매 틱) | 평형에서 비어 있는 자리 비율 φ (스냅샷 노출, 진단용) | 0~1 | |

교환성 양 = 총량 − 녹은 양 (파생, 스냅샷·CSV에 노출). 토양 검정(M7)이 보여줄 값이에요.

> 단위 감각: 흙 240 kg/m²에서 CEC 1 cmol/kg = 2.4 eq/m². 양토 30 eq/m² ≈ 12.5 cmol/kg, 사토 6 eq/m² ≈ 2.5 cmol/kg.

## 프로세스

### CEC (셀 단계 f2, 매 틱)

```
cec = cec_mineral + cec_organic_eq_per_g_C × stable_C
```

- 난분해성 C만 써요. 숙성 퇴비(대부분 난분해성 풀로 들어감)는 바로 CEC를 올리고, 미숙 퇴비는 분해·부식화를 거친 뒤에 올려요.

### 평형 분배: 빈자리 경쟁 (셀 단계 f2)

양이온 i ∈ {NH4, K, Ca, Mg, Mn}의 총량을 당량으로 `T_i = 총량_i / g_per_eq_i`, 세기를 `w_i`(Mn은 pH 의존 `retention_ph_curve(pH)`)라 할 때, 빈자리 비율 φ ∈ [0, 1]는 아래 식의 해예요.

```
교환성_i(φ) = T_i × w_i·φ / (1 + w_i·φ)
cec × (1 − φ) = Σ_i 교환성_i(φ)          ← "차지된 자리 = 붙은 양이온"
```

- 왼쪽은 φ에 대해 감소, 오른쪽은 증가라서 해가 하나예요. **이분법을 `solver_iterations`회** 고정 반복해요(결정론, 반복 횟수 고정).
- 평형 용액 양: `용액*_i = T_i / (1 + w_i·φ)` (당량 → g 환산).
- 방향:
  - 양이온 합이 CEC보다 한참 작으면 φ가 커서 대부분 붙어 있어요.
  - 양이온 합이 CEC에 가까워지거나 넘으면 φ → 0이 되고, **남는 양이온이 세기가 약한 순서(NH4, K)부터 용액으로** 나와요. 사토에 한 번에 많이 주면 생기는 일이에요.
  - 한 이온을 많이 넣으면 φ가 줄어 **다른 이온의 용액 양도 늘어요**(밀려남). 이게 S5의 "Ca가 밀려나 용탈 위험 증가"예요.
- 예외: `cec ≤ 0`이면 φ = 0으로 두고 전부 용액 (`용액* = T`). `ΣT = 0`이면 φ = 1. (2026-11-18 프로토타입 점검에서 φ 값 명시)
- **초기화 순서**: 월드 생성 시 통기 지수를 먼저 계산한 뒤 평형을 구해 용액 상태를 채워요. 세이브를 불러올 때는 저장된 용액 상태를 그대로 쓰고 평형을 다시 구하지 않아요. (2026-11-18 프로토타입 점검에서 명시)
- φ의 뜻: 염기 양이온이 차지하지 않은 자리(실제로는 H+·Al 등이 차지). **pH와는 연결하지 않아요**(단순화 참고).

### 완화 (셀 단계 f2)

```
용액_i += (용액*_i − 용액_i) × min(1, exchange_rate_per_hour)
0 ≤ 용액_i ≤ 총량_i 로 제한
```

- 이동은 총량 안에서 붙은 쪽 ↔ 녹은 쪽이라 총량은 그대로예요(장부 변화 없음).

### 다른 프로세스와의 연결 (용액 상태를 쓰는 규칙)

| 프로세스 | 총량 | 용액 |
| --- | --- | --- |
| 비료·퇴비 무기 성분 (명령) | + 투입량 | + 투입량 (먼저 녹은 채로 들어가요) |
| 석회 용해 Ca·Mg (단계 g) | + | + |
| 유기물 분해의 NH4 무기화 (단계 e) | + | + |
| 부동화로 NH4 감소 (단계 e), 질산화 1단계 (단계 f) | − | **비례 차감**: `용액 × (새 총량 / 옛 총량)` |
| 작물 흡수 (단계 h) | − | − 같은 양 (흡수는 유효량 = 용액 × pH 유효도 안에서만) |
| 뿌리 고사 양분 반환 (단계 h) | + | + (K·Ca·Mg·Mn. N은 M2처럼 이분해성 유기 N으로) |
| 용탈 (단계 i) | − | − `용액 × f` (f = 배수 비율, M1·M2와 같음) |

"총량을 바꾸는데 용액을 명시하지 않은" 프로세스가 새로 생기면 비례 차감을 기본 규칙으로 해요.

### 유효량·EC·용탈 (M2 식에서 바뀌는 부분)

- `solution_X`를 M2의 `풀 × X_solution_fraction` 대신 **용액 상태**로 써요 (NH4, K, Ca, Mg, Mn).
- P·S·NO3·NO2는 M2 그대로예요 (음이온은 교환 자리에 붙지 않아요. P는 [phosphorus](phosphorus.md)).
- EC: M2 식에 Mn 용액을 양이온으로 더해요. (양이온 + 음이온) ÷ 2 근사는 그대로예요 (`balancing.md` 15번은 계속 열어 둬요).
- 삭제되는 M2 파라미터: `soil_chemistry.k_solution_fraction`, `ca_solution_fraction`, `mg_solution_fraction`, `leaching.nh4_solution_fraction`.

### pH 완충력 (단계 g, M2 식에 항 추가)

```
buffer = base_buffer + buffer_eq_per_pH_per_eq_cec × cec_mineral + organic_C_buffer × 유기 C
```

- 광물 CEC만 더해요. 유기물 몫은 M2의 `organic_C_buffer` 항이 이미 맡고 있어서 두 번 세지 않아요.
- `base_buffer`는 "CEC 밖 완충(탄산염·광물 풍화 등)"으로 뜻을 좁혀요. M1·M2 시나리오는 이행 시 총 완충력이 M2와 같도록 줄여요([m3-overview](m3-overview.md) "시나리오 이행").

### 흡수 길항 (단계 h, [strawberry-minimal](strawberry-minimal.md) 흡수 식에 계수 추가)

```
antagonism_index = (용액 K + 용액 NH4) [eq] / (용액 Ca + 용액 Mg) [eq]     (분모 0이면 길항 없음: 배율 1)
a_Ca = antagonism.ca_curve(antagonism_index)
a_Mg = antagonism.mg_curve(antagonism_index)

capacity_X  = available_X × min(1, X_uptake_rate × root × root_health) × water × salt × a_X   (X = Ca, Mg)
demand_X    = max(0, target_X × luxury_uptake_ratio × max(min_demand_factor, a_X) × (leaf + root) − plant_X)   ← 2026-11-18 개정
```

- **(2026-11-18 프로토타입 점검)** Ca·Mg는 전용 흡수 속도를 써요. 일반 속도(0.002)로는 흡수 능력이 필요량의 30~100배라서 길항 배율이 아무리 낮아도 흡수가 줄지 않았어요.
- **(2026-11-18 디렉터 결정, 2차 프로토타입 점검 반영)** 길항은 흡수 능력뿐 아니라 **수요 상한**에도 걸려요. 근거는 식물 체내 양이온 균형이에요. K·NH4를 많이 먹으면 체내에서 Ca·Mg가 들어갈 몫이 줄어요. 흡수 능력에만 걸면 여유 능력이 잠깐의 경쟁을 나중에 메워서, 체내 Ca 농도가 늘 상한(1.3배)까지 차고 길항이 결과에 남지 않았어요.
- 체내 양을 빼앗지는 않아요. 상한이 낮아지면 그 뒤 흡수가 멈추고, 생장 희석으로 체내 농도가 내려가요.
- 수요 상한의 배율에는 하한 `min_demand_factor`가 있어요. 4차 점검에서 하한 없이 돌렸더니, 사토(S6)에서 길항 배율이 평균 0.33까지 떨어져 Ca·Mg 흡수가 21일 내내 0이 됐어요(질산칼슘을 넣어도 마찬가지). 하한이 있으면 결핍은 생기되 흡수가 멈추지는 않아요.
- 1가 양이온(K, NH4)이 많으면 2가 양이온(Ca, Mg) 흡수가 밀려요. 토양 검정에서 보는 "K/(Ca+Mg) 당량비"와 같은 방향의 지표예요.
- **NH4를 포함한 이유**: 암모늄 비료 과다도 Ca 흡수를 떨어뜨려(현실에서 팁번 원인), "Ca 결핍 증상 → 원인이 K인지 NH4인지 pH인지"를 측정으로 가려야 하는 겹침이 생겨요(계획서 5장 "증상은 겹치게").
- 길항 배율은 이번 틱 값이고 스냅샷에 노출해요(진단·그래프용).

## 틱 처리 순서 내 위치

질산화(f) 다음, 석회·pH(g) 앞의 **f2 양이온 교환**. 망간 산화·환원([manganese](manganese.md))을 먼저 하고 교환을 계산해요. 계획서 4장 순서 "유기물 분해 → 질산화 → 양이온 교환 → pH"를 따라요.

## 보존·불변 조건

- 원소별 총량 보존은 M2 장부 그대로예요(교환은 계 안의 이동). Mn 장부가 추가돼요([manganese](manganese.md)).
- 매 틱: `0 ≤ 용액_i ≤ 총량_i`, `cec > 0`이면 `Σ 교환성_i(평형) ≤ cec`, `0 ≤ φ ≤ 1`, NaN 없음.

## 테스트 (단위)

| 조건 | 기대 |
| --- | --- |
| 기준 토양 평형 | 용액 비율이 M2 고정값(NH4 0.1, K 0.03, Ca 0.01, Mg 0.02)과 ±10% 안 |
| 평형 해 | `cec × (1 − φ) = Σ 교환성` 잔차가 cec의 1e-9 이하 |
| 같은 양이온, CEC 절반 | 모든 이온의 용액 비율 증가 |
| 양이온 합 > CEC | 교환성 합 ≤ CEC, 남는 양은 용액으로, 용액 비율은 NH4 > K > Mg > Ca |
| K 대량 투입 | Ca·Mg 용액 양 증가 (밀려남) |
| 비료 투입 직후 | 투입분이 전부 용액. 이후 틱마다 평형 쪽으로 움직이고 넘어서지 않음 |
| 완화 속도 1 | 한 틱에 평형 도달 |
| 숙성 퇴비 투입 | 같은 틱 이후 CEC 증가. 미숙 퇴비는 즉시 증가분이 더 작음 |
| 질산화로 NH4 총량 절반 | NH4 용액도 절반 (비례 차감) |
| 같은 산, 광물 CEC 큼 | pH 변화폭 작음 |
| 길항 지수 0.2 대 1.0, 나머지 같음 | Ca·Mg 흡수 능력이 1.0 쪽에서 작음. K 흡수 능력은 같음 |
| `cec ≤ 0` 또는 양이온 0 | NaN 없음, 용액 = 총량 |

## 단순화와 비목표

- **φ(빈자리)와 pH를 연결하지 않아요.** 현실에서는 염기포화도와 pH가 함께 움직이지만, pH는 M2 산·염기 수지가 따로 맡아요. 두 번 세지 않으려는 선택이에요(ADR-0008).
- CEC의 pH 의존성(유기물 가변 전하)은 없어요.
- 나트륨·알루미늄·수소 이온은 상태로 두지 않아요. 비어 있는 자리 φ가 그 몫이에요.
- 선택 계수는 이온 쌍마다가 아니라 이온마다 하나예요(Gapon·Vanselow 식 대신 경쟁 랭뮤어 근사).
- K 고정(일라이트 층간 고정) 같은 비교환성 K는 없어요.
- Ca 흡수의 증산류 의존(실제 팁번의 핵심 기작)은 환기·습도가 생기는 M7에서 다시 봐요.
