# M6a 시나리오

M6a(엔진 연결)에서 새로 만든 시나리오예요. 기존 시나리오와 기준값(`tests/baselines/`)은 건드리지 않았어요.
값은 전부 게임용 임의값이에요.

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| `direct_play.toml` | 게임의 "직접 플레이" 판 (m6-overview 결정 D3·F1), 엔진 검사 E10 | `m4/season_standard`와 같은 시작일(day 253, 9월 10일)·시드·하우스(4 × 20, 3겹, 점적 설치)·흙·미생물·병해 배경·날씨예요. **작물이 없고(`[crop]` 없음) 일정표도 없어요.** 밑거름·정식부터 플레이어가 해요. 길이는 게임 쪽 시나리오 목록이 정해요(기준 1작기 263일 = 6,312틱) |
| `all_commands.toml` | 엔진 검사 E2(일정표대로 CLI와 모든 틱 비교), E4·E6(일정표를 끄고 가짜 플레이어) | 코어 명령 17종이 전부 들어 있는 30일(720틱) 판이에요. 기존 M5a·M5b 시나리오 일정표에는 포기 제거·피복 변경·점적 설치가 없어서 만들었어요. 피복 변경 기간(day 91~243) 안인 day 240에 시작하고, 점적 없이·작물 없이 시작해 틱 120에 정식해요. 시뮬레이션 기준값으로 쓰지 않아요 |

- 두 파일 모두 `tests/test_loader.cpp`의 "모든 시나리오가 읽힌다" 검사에 자동으로 들어가요.
- 엔진은 빌드가 복사한 `game/data/scenarios/m6/`(`res://data/scenarios/m6/`)를 읽어요.
